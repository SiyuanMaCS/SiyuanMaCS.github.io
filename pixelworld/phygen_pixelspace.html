PhyGenBench 官方 T2V 与 I2V 扩展

正式 T2V 使用 160 条官方物理 prompt；I2V 扩展在同一 prompt 上加入高质量预动作首帧，用来分析初始视觉状态如何改变 direct-RGB coding agent 的生成边界。

smoke running

T2V 从文本直接生成全部帧并进入官方 PhyGenBench 评测；I2V 使用 Qwen-Image-2.1 生成并人工核验的预动作首帧。Qwen 从不参与视频后续帧生成，I2V 分数单独报告为 PixelWorld 扩展。

两种条件均禁止 3D renderer、物理引擎和外部图像/视频模型；但允许 Python/NumPy/PIL 的局部像素、纹理、光照、warp 和运动计算。
