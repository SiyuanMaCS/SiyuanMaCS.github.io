输入、协议与评测

正式数据共 129 条、20 个刚体场景：质量 32、摩擦 21、恢复系数 13、初始速度 26、添加 7、删除 30。117 条从首帧干预，12 条在中途干预。

采用官方 quantitative.en。指令帧号从 1 开始，第 1 帧对应 0 秒。编辑前保留事实历史；编辑后生成物理变化引起的运动及其他受影响物体的交互。

Agent 只读原视频、RGB 数组、输入检查图与指令；不提供 edited_video、ground_truth、physics_diff 或 edit_summary。仍用代码直接写 RGB，不调用图像/视频生成模型或外部物理仿真/渲染引擎；允许 Python 数学、几何与像素操作。

官方评测：PES、轨迹误差 TE、Mask IoU，以及 PSNR/SSIM/LPIPS/CLIP/FVD。GroundingDINO＋SAM2、I3D 和真值仅留在评测侧；每个模型/Track 完成 129 条后进入原版评测。尚未报告 PCVE 分数。
